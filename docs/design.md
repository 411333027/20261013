# 匿名聊天室：畫面設計規格

> 這份文件整理 /design 的設計結果，給做前端（/frontend-design）時使用。
> 設計稿（畫布）：<https://claude.ai/artifact/TU2T2nN7wJk4dDbGtJhNEe>（目前只有擁有者看得到）
> 畫面上「有什麼、會做什麼」以 `docs/architecture.md` 第 7 節為準；這份文件只規定**長什麼樣子**。

---

## 1. 風格

**貼紙風、明亮聊天 App。**

- 淡薄荷白的底色，上面鋪細小的點點底紋。
- 按鈕、對話泡泡、卡片都有**深墨綠色的粗外框**，右下角有**實心錯位陰影**（不模糊），看起來像一張張貼紙。
- 主色是**淺藍綠色**。
- 標題、代號、按鈕用圓體字（粉圓體），內文用一般黑體，親切又好讀。
- 代表圖示是一個**歪一邊的眼罩面具**，對應「匿名」。
- 手機優先，電腦版是同一套元素的放大排版。

## 2. 顏色

建議在 `css/style.css` 的 `:root` 定義成 CSS 變數（CSS 變數：把顏色取一個名字，之後要改只改一個地方）。

| 變數名稱 | 色碼 | 用在哪裡 |
|---|---|---|
| `--ink` | `#12343B` | 主要文字、所有外框、錯位陰影、斷線提示條的底色 |
| `--muted` | `#4A6670` | 次要文字：時間、說明文字、（你） |
| `--ground` | `#F3FBF8` | 頁面底色、輸入框底色 |
| `--dot` | `rgba(18,52,59,0.12)` | 點點底紋 |
| `--surface` | `#FFFFFF` | 頂端列、輸入區、卡片、別人的對話泡泡 |
| `--accent` | `#5EEAD4` | 主要按鈕（進入、送出、有新訊息）、面具圖示的底、展開時的人數膠囊 |
| `--own` | `#CCFBF1` | 自己的對話泡泡 |
| `--link` | `#0F766E` | 文字連結（目前畫面上沒有用到，保留） |
| `--demo` | `#FFE58F` | 示範模式標示條、「你送太快了」小標籤 |
| `--danger` | `#B42318` | 錯誤文字、錯誤外框、「沒有送出」 |
| `--danger-bg` | `#FFF1EE` | 錯誤的輸入框底色、「沒有送出」小標籤的底 |
| `--online` | `#16A34A` | 「線上」綠點 |
| `--disabled-bg` | `#E3ECE9` | 不能按的按鈕底色 |
| `--disabled-border` | `#9DB3B0` | 不能按的按鈕外框；斷線時的灰點 |

**每個人的識別色**（頭像底色和「#三碼」標籤底色共用，從身分編號算出來，依序取用）：

| 名稱 | 色碼 |
|---|---|
| 紫 | `#EDE9FE` |
| 綠 | `#DCFCE7` |
| 藍 | `#DBEAFE` |
| 橘 | `#FFEDD5` |

> 實作時可以再多加幾個淡色，但都要夠淡，讓深墨綠色的字讀得清楚。

**對比度**：所有文字都是深色字配淺色底，或白字配 `--ink` 底，符合 4.5:1 的可讀標準。**不要**在 `--accent` 或 `--own` 上放白字，會看不清楚。

## 3. 字體

從 Google Fonts 載入：

```html
<link href="https://fonts.googleapis.com/css2?family=Huninn&family=Noto+Sans+TC:wght@400;500;700&display=swap" rel="stylesheet">
```

| 用途 | 字體 | 大小 |
|---|---|---|
| 進入畫面的大標題 | Huninn（粉圓體） | 36px，字距 0.04em |
| 頂端列的聊天室名稱 | Huninn | 手機 19px／電腦 22px |
| 按鈕文字 | Huninn | 16px（進入按鈕 20px） |
| 代號、頭像裡的字 | Huninn | 13～15px |
| 系統訊息、只有你一個人的提示 | Huninn | 13px／17px |
| 訊息內容、輸入框 | Noto Sans TC | 15px，行高 1.55 |
| 說明文字、提示 | Noto Sans TC | 13px |
| 時間 | Noto Sans TC | 11px，`--muted` |

Huninn 只有一種粗細，不要對它設定 `font-weight: bold`。

## 4. 共通樣式

| 項目 | 規格 |
|---|---|
| 點點底紋 | `background-color: var(--ground); background-image: radial-gradient(var(--dot) 1.2px, transparent 1.6px); background-size: 18px 18px;` |
| 粗外框 | `2px solid var(--ink)`（小標籤用 `1.5px`） |
| 錯位陰影 | 大卡片 `5px 5px 0 var(--ink)`；按鈕 `3px 3px 0`～`4px 4px 0`；對話泡泡 `2px 2px 0` |
| 圓角 | 大卡片 22～24px；按鈕、輸入框 14～18px；頭像 12px；小標籤、膠囊 999px（完全圓） |
| 可點擊區域 | 所有按鈕至少 44px 高 |
| 分隔線 | 頂端列下方、輸入區上方都用 `2px solid var(--ink)` |

## 5. 元件

### 5.1 面具圖示

一個圓角方塊，`--accent` 底、粗外框，**逆時針轉 6 度**，裡面是白色填色、深色描邊的眼罩面具。

| 位置 | 方塊大小 | 圓角 | 陰影 |
|---|---|---|---|
| 進入畫面 | 112px | 36px | `5px 5px 0` |
| 頂端列（手機） | 42px | 14px | 無 |
| 頂端列（電腦） | 44px | 14px | 無 |

面具的 SVG：

```html
<svg aria-hidden="true" viewBox="0 0 24 24" fill="#FFFFFF" stroke="#12343B" stroke-width="1.6" stroke-linejoin="round" stroke-linecap="round">
  <path d="M2.5 8.5c3.2-1.6 6.3-1.6 9.5 0 3.2-1.6 6.3-1.6 9.5 0 0 5.2-2.6 8.2-5.2 8.2-2.1 0-3.1-2-4.3-2s-2.2 2-4.3 2c-2.6 0-5.2-3-5.2-8.2z"/>
  <path d="M6.6 11.6c.8-.7 2-.7 2.8 0" fill="none"/>
  <path d="M14.6 11.6c.8-.7 2-.7 2.8 0" fill="none"/>
</svg>
```

（頂端列的小圖示可以省略兩條眼睛的線。）

### 5.2 按鈕

| 種類 | 底色 | 外框 | 陰影 | 用在 |
|---|---|---|---|---|
| 主要 | `--accent` | `--ink` | 3～4px 錯位 | 進入、送出、有新訊息 ↓ |
| 次要 | `--surface` | `--ink` | 3px 錯位 | 離開 |
| 不能按 | `--disabled-bg` | `--disabled-border` | 無 | 送出（斷線、空白、超過 500 字、送太快時），文字 `--muted` |

### 5.3 對話泡泡

| | 別人的訊息 | 自己的訊息 |
|---|---|---|
| 位置 | 靠左，前面有頭像 | 靠右，沒有頭像和代號 |
| 最大寬度 | 手機 86%／電腦 72% | 手機 80%／電腦 70% |
| 底色 | `--surface` | `--own` |
| 圓角 | `4px 16px 16px 16px`（左上角尖） | `16px 4px 16px 16px`（右上角尖） |
| 外框、陰影 | 2px 粗外框＋`2px 2px 0` 錯位陰影 | 同左 |
| 內距 | `9px 13px` | 同左 |
| 時間 | 泡泡右下方外側 | 泡泡左下方外側 |
| 換行 | `white-space: pre-wrap`（保留換行）；網址加 `word-break: break-all` 避免撐破版面 | 同左 |

**別人的訊息**由上到下是：代號（Huninn 13px）＋「#三碼」小標籤 → 泡泡＋時間。頭像在左側，和代號頂端對齊。

**沒有送出**：泡泡改成白底、`2px dashed var(--danger)`（紅色虛線框）、沒有陰影、文字 `--muted`。泡泡下方靠右放一個小標籤：`--danger-bg` 底、`1.5px solid var(--danger)`，紅字「! 沒有送出」。

### 5.4 頭像與同名標記

- **頭像**：34px（電腦版訊息區 36px）的圓角方塊，識別色底、2px 粗外框，中間是代號的第一個字（Huninn）。
- **「#三碼」標籤**：11px 字、`1.5px` 粗外框、完全圓角，底色和頭像相同。
- 頭像和標籤都從同一個身分編號算出來，所以同一個人的顏色一致。

### 5.5 系統訊息

聊天區正中間的一顆膠囊：白底、`2px dashed var(--ink)`（虛線框），前面有 Wi-Fi 圖示，文字 Huninn 13px。目前只有一種：「你剛剛斷線了，期間的訊息沒有收到」。

### 5.6 示範模式標示條

最上方一整條：`--demo` 底、下方 2px 粗外框、13px 字。

- 左邊：「示範模式：還沒連上真正的聊天室」。
- 右邊（只在聊天畫面）：「模擬斷線」開關。
  - **關**：白底軌道、深色圓點在左。
  - **開**：深色軌道、黃色圓點在右，文字變粗。
  - 必須用 `<button role="switch" aria-checked>`。

### 5.7 連線狀態列

在頂端列下方，`--ink` 底、白字 14px，前面有一個 `--accent` 色的轉圈圖示。

- 「連線中斷，正在重新連線…」
- 「連線中…」（樣式相同）
- 正常連線時不顯示。

斷線時，聊天區的訊息整體降低透明度到 0.6，人數旁的綠點改成灰點（`--disabled-border`）。

### 5.8 線上人數與名單

- **人數膠囊**（手機，在聊天室名稱下方）：`1.5px` 粗外框、完全圓角、13px 字，內容是「● 線上 N 人 ⌄」。
  - **收起時**：`--ground` 底。
  - **展開時**：`--accent` 底，箭頭朝上。
  - 必須是 `<button aria-expanded>`。
- **展開的名單**（手機）：浮在頂端列下方的白色卡片，左右各留 12px、粗外框、`4px 4px 0` 錯位陰影、圓角 18px，會蓋住聊天區。
- **名單的每一列**：最少 44px 高，內容是頭像、代號（Huninn）、「#三碼」標籤，自己還有「（你）」。自己排第一。
- **電腦版**：名單是右側一張獨立的卡片（見 6.7），人數膠囊放在卡片頂端，`--accent` 底。

### 5.9 輸入區

白底、上方 2px 粗外框。

- **輸入框**：`--ground` 底、2px 粗外框、圓角 18px、最少 46px 高；超過 500 字時外框和底色改成紅色系（`--danger`／`--danger-bg`）。
- **送出按鈕**：在輸入框右邊，主要按鈕樣式，46px 高。
- **提示**：放在輸入框上方。
  - 「你送太快了，請稍等幾秒」：`--demo` 底的小標籤，有時鐘圖示。
  - 「超過 500 字」：紅字，右邊顯示「523/500」這樣的字數。
  - 斷線時：`--muted` 字，「連上之後才能送出，打好的字會留著」。
- **電腦版**：輸入框下方多一行 12px 的「Enter 送出・Shift+Enter 換行」。
- 輸入框一定要有 `<label>`（可以用視覺上隱藏的方式）。

### 5.10 「有新訊息 ↓」按鈕

浮在聊天區底部正中間，主要按鈕樣式，完全圓角、44px 高。

### 5.11 只有你一個人

聊天區正中間一張白色卡片，粗外框、`5px 5px 0` 錯位陰影、**順時針轉 -2 度**。內容是 `--own` 色的大面具，下面兩行 Huninn 17px：「目前只有你在這裡」、「把網址分享給朋友吧」。

## 6. 畫面

設計稿上的編號和名稱：

| # | 畫面 | 重點 |
|---|---|---|
| 1 | 進入畫面 | 上半部：大面具、大標題、一句說明；下半部：白色大卡片，裡面有代號輸入框（預先填好）、「上次用的代號…」說明和「2/10」字數、「進入」按鈕。整體垂直置中 |
| 2 | 進入畫面・代號不符合規則 | 輸入框變成紅框紅底，下方紅字和驚嘆號圖示：「請輸入代號（1～10 個字，不能只有空白）」；其他錯誤文字（例如「代號最多 10 個字」）放在同一個位置 |
| 3 | 聊天中 | 由上到下：示範模式條 → 頂端列（面具、名稱、人數膠囊、離開）→ 聊天區（點點底紋，訊息貼齊底部）→ 輸入區。畫面上有同名的三個「小明」、多行訊息、網址、沒有送出的訊息、「有新訊息 ↓」、「你送太快了」 |
| 4 | 只有你一個人・名單展開 | 名單卡片展開，只有自己一列；中間是「只有你一個人」卡片；輸入區顯示「超過 500 字」 |
| 5 | 斷線中 | 頂端列下方出現深色狀態列；開關在「開」；訊息降低透明度；送出按鈕不能按，打好的字還在 |
| 6 | 連回來之後 | 狀態列消失；訊息之間出現虛線膠囊的系統訊息；送出按鈕恢復可以按 |
| 7 | 電腦版・聊天中 | 頂端列橫跨整個寬度；下面左右兩張浮在點點底紋上的大卡片：左邊是聊天卡片（訊息區最寬 820px 置中、輸入區在卡片底部），右邊是線上名單卡片（約 260px 寬，靠上）；兩張卡片間距 20px，外圍留 20～24px |

### 版面尺寸

- **手機**：以 390px 寬設計。整頁剛好是螢幕高度，只有聊天區可以捲動，示範模式條、頂端列、輸入區都固定不動。
- **電腦**：以 1280px 寬設計。聊天卡片 `flex: 999 1 560px`，名單卡片 `flex: 1 1 260px`，外層 `flex-wrap: wrap`，畫面太窄時名單會掉到下面。
- **手機和電腦的切換點**：建議在 **768px**。比它窄時用手機版（名單收起來，點人數才展開）；比它寬時用電腦版（名單一直顯示在右邊）。

## 7. 設計稿以外、實作時要補的

- **鍵盤焦點**：設計稿把輸入框的 `outline` 拿掉了。實作時要加回明顯的焦點樣式，例如外框加粗成 3px 的 `--link` 色，讓用鍵盤操作的人知道現在在哪裡。
- **按下去的回饋**：按鈕被按下時，陰影縮成 0、按鈕往右下移動相同距離，像把貼紙壓下去。
- **深色模式**：這一版不做。
